# Versha Associates — Digital Enablement Platform

A professional website for **Versha Associates**, an A-Class Licensed Electrical Contractor based in Loni, Ghaziabad, Uttar Pradesh.

## About the Business

Versha Associates is a licensed **A-Class Electrical Contractor** (License No. GD00001264, issued by UP Government, Directorate of Electrical Safety). The firm is owned and operated by **Moolchand** and has been in operation since 2017. It is the highest tier of electrical contracting license in Uttar Pradesh.

## Project Overview

This project is part of the **Small Business Digital Enablement** initiative. The goal is to provide Versha Associates with:

- A professional public website (online presence)
- A tender/bid tracking dashboard (Phase 2)
- A digital invoice log (Phase 3)

## Tech Stack

- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Deployment:** Vercel

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
